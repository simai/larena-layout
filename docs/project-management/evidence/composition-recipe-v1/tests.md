# Проверки

- compact и expanded выбирают разные шапки;
- текст поступает из существующей PageComposition;
- receipt содержит только выбранный fragment;
- чужой scope и неверный отпечаток Framework отклоняются;
- compact и expanded сохраняются разными полными снимками;
- устаревшая ревизия не меняет активный результат;
- откат возвращает прежний снимок и увеличивает ревизию активации;
- ошибка сборки не меняет активный снимок;
- отзыв доступа запрещает чтение ранее собранного результата;
- браузер показывает активный HTML на ширинах 1440 и 390 px без переполнения и ошибок консоли;
- полный quality gate пакета проходит.
